# TROUBLESHOOTING
# ===============

Q: "ModuleNotFoundError: No module named 'fastapi'"
A: Run: pip install -r requirements.txt

Q: "Address already in use :8000"
A: Either:
   - Kill the process: taskkill /PID <pid> /F (Windows)
   - Or use different port: uvicorn backend.main:app --port 8001

Q: "Frontend shows 'Disconnected'"
A: Backend not running. Make sure http://127.0.0.1:8000 is accessible

Q: Database errors
A: Delete data/soc.db and restart (will be auto-recreated)
